# README：通用佛学专题补充说明

## 定位

这组 `BT*` 文件用于补充东林寺定制问答里的通用佛学常识，让系统在不偏离净土主轴的前提下，也能回答更基础、更普遍的佛学问题。

## 原则

- 仍以大白话、科普化表达为主
- 以汉传佛教常见口径为基础
- 避免过度学术化或宗派争论化
- 让通用佛学成为“辅助层”，不压过净土主线

## 与旧资料的关系

- `金刚经.md` 作为经典原文白名单保留进索引
- `金刚经讲记_圣严法师.md` 保留原文件，但默认不直接进索引
- 改由 `BT12_金刚经讲记导读_圣严法师整理版.md` 进入索引
- 原始 `pdf` 和归档转写文件默认不进索引
- 其他旧资料维持默认忽略，避免知识库重新发散
