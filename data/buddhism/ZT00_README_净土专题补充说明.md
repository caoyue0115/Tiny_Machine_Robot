# README：净土专题补充说明

## 本批文件说明

本批 `md` 文件不是对公开网页的原文搬运，而是基于公开资料整理出的原创知识卡，目的是让 RAG 更容易回答以下场景：

- 东林寺定制问答
- 阿弥陀佛与净土宗基础介绍
- 《无量寿经》及相关净土经典的大白话解释
- 念佛、愿力、往生、极乐世界等高频问题

## 设计原则

- 优先“能回答用户问题”，不是优先“经文越长越好”
- 优先大白话、科普化表达
- 每篇都保留适合回答的问题，方便做 chunk 后命中
- 每篇都保留来源链接，便于后续人工校核

## 建议后续动作

- 将这些文件与现有佛经原文分层索引
- 对“阿弥陀佛、无量寿经、东林寺、念佛”相关关键词提高召回权重
- 若需要更强解释力，可继续补 10 到 20 篇专题卡，如“法藏比丘”“第十八愿”“往生不是逃避现实”等
