# v29 No-Intro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Disable the realtime answer intro prompt without breaking the pre-record prompt or OTA P2 dry-run behavior.

**Architecture:** Keep the feature as a compile-time default change in `esp_idf_demo/main/config.h`. Adjust startup SPIFFS mounting in `esp_idf_demo/main/main.c` so audio assets remain available when record prompt is enabled and intro is disabled.

**Tech Stack:** ESP-IDF C firmware, Python unittest/pytest asset tests, compile-only ESP handoff package.
