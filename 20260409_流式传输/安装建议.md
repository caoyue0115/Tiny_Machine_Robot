# 安装建议

日期：`2026-04-10`

这份文档只记录当前阶段最有价值的本地与云端工具，不追求面面俱到。

## 1. 本地建议安装

### 1.1 必装

- `python3`
- `python3-venv`
- `pip`
- `ssh`
- `scp`
- `curl`
- `git`

### 1.2 强烈建议

- `jq`
  - 快速查看 `/sessions/{id}` 的 `trace`
- `ffmpeg`
  - 看音频文件信息、转码、抽样
- `ffplay`
  - 快速试听下载下来的音频
- `sox`
  - 看采样率、声道、位宽，做轻量音频处理
- `screen` 或 `tmux`
  - 长时间跑串口、日志、远端命令更方便

### 1.3 ESP 开发环境

- `ESP-IDF 5.5.4`
- `idf.py`
- 串口工具链

## 2. 云端建议安装

### 2.1 必装

- `python3`
- `curl`
- `docker`
- `docker compose`

### 2.2 强烈建议

- `jq`
  - 直接看健康检查和接口返回
- `ffmpeg`
  - 远端排查音频产物很有用
- `sox`
  - 可选，但对音频快速检查方便

## 3. 常用命令

### 3.1 本地看 realtime trace

```bash
python -c "import httpx, json; print(json.dumps(httpx.get('http://<CURRENT_BASE_URL>/api/v3/realtime/sessions/<session_id>', timeout=10).json(), ensure_ascii=False, indent=2))"
```

### 3.2 远端看健康检查

```bash
curl -sS http://<CURRENT_BASE_URL>/healthz | jq
```

### 3.3 本地跑 v3 smoke

```bash
cd /home/aitopia/Engineering_Projects/.worktrees/religion-demo-20260407/20260407_宗教大模型云服务器Demo
BASE_URL=http://<CURRENT_BASE_URL> python scripts/realtime_smoke.py ./data/output/demo_test_question_24k.wav --max-polls 60
```

## 4. 当前不必优先装的东西

- 不必为了 `v3` 第一轮联调单独装复杂监控栈
- 不必为了 realtime TTS 第一轮联调上连接池或额外代理
- 不必现在就做专门的音频可视化 GUI

当前阶段重点仍然是：

- 板端能稳定创建 session
- 板端能稳定边收边播
- 板端观测值能和云端 trace 对齐
