# 系统架构图

## 1. 总体结构

```text
┌────────────────────┐
│ ESP-VoCat v1.2     │
│ ESP32-S3-WROOM-1   │
└─────────┬──────────┘
          │
          │ touch trigger
          ▼
┌────────────────────┐
│ trigger_input.c    │
└─────────┬──────────┘
          │
          ▼
┌────────────────────┐
│ main.c             │
│ pipeline task      │
└─────┬──────┬───────┘
      │      │
      │      │
      │      ▼
      │   ┌────────────────────┐
      │   │ cloud_client.c     │
      │   │ submit / poll      │
      │   └─────────┬──────────┘
      │             │
      │             ▼
      │   ┌────────────────────┐
      │   │ Cloud Server       │
      │   │ /api/v2/tasks      │
      │   │ worker / RAG / LLM │
      │   │ TTS / audio_url    │
      │   └─────────┬──────────┘
      │             │
      │             ▼
      │   ┌────────────────────┐
      │   │ audio_out.c        │
      │   │ WAV download/play  │
      │   └────────────────────┘
      │
      ▼
┌────────────────────┐
│ audio_in.c         │
│ board mic record   │
└────────────────────┘
```

## 2. 当前设备端主流程

```text
Touch
  -> record 4s PCM
  -> POST /api/v2/tasks
  -> poll task status
  -> get audio_url
  -> download WAV
  -> play on board speaker
```

## 3. 模块职责

- `trigger_input.c`
  - 触摸触发输入
- `main.c`
  - 状态机与 pipeline 编排
- `audio_in.c`
  - 板载麦克风录音
- `cloud_client.c`
  - 上传、轮询、网络容错
- `audio_out.c`
  - WAV 下载、解析、播放兼容

## 4. 服务端主流程

```text
POST /api/v2/tasks
  -> save input wav
  -> enqueue worker
  -> ASR
  -> retrieval
  -> LLM
  -> TTS
  -> save output wav
  -> expose audio_url
```
