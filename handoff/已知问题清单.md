# 已知问题清单

## 1. 当前已知但不阻塞交接的问题

### 1.1 录音质量稳定性仍受环境影响

表现：

- 有时能正常识别
- 有时返回 `asr_empty_text`

影响：

- 不是链路坏掉
- 但实板体验会受说话时机、增益、环境噪声影响

当前建议：

- 先调 `DEMO_AUDIO_INPUT_GAIN_DB`
- 触摸后尽快说话

### 1.2 云端返回的 WAV 头不总是完全规范

表现：

- `data` chunk 长度字段可能大于文件实际剩余长度
- 尾部可能存在不完整帧

当前状态：

- 板端已做兼容处理
- 不再把这类 WAV 直接判死

### 1.3 轮询阶段仍可能受网络波动影响

表现：

- 单次请求偶发超时

当前状态：

- 已对 `ESP_ERR_HTTP_EAGAIN` / `ESP_ERR_TIMEOUT` 做最小重试
- 但极端网络波动下仍可能触发总超时失败

## 2. 当前不在稳定交接范围内的内容

- `v3/realtime` 低延迟新方案
- Koze 端到端语音方案
- 提示词唤醒
- 更复杂的屏幕 UI

## 3. 当前系统边界

当前系统定位是：

- 一个可联调、可演示、可交接的语音问答 Demo

不是：

- 最终产品固件
- 完整实时对话系统
- Coze 等平台型方案的同等替代品
