# 稳定交接包说明

## 1. 目标

这份说明用于明确“当前什么内容算稳定交接资产”，以及拿到交接包后应该先看什么。

## 2. 当前稳定交接范围

当前稳定可交接的内容包括：

- 设备端参考工程：`esp_idf_demo/`
- 云端接口契约：`/api/v5/realtime/opus-stream`
- 状态兼容接口：`/api/v3/realtime/sessions/{session_id}`
- OTA manifest 接口：`/api/v5/ota/manifest`
- OTA firmware 下载接口：`/api/v5/ota/firmware/{artifact_name}`
- OTA report 接口：`/api/v5/ota/report`
- 硬件联调说明
- 快速启动和排障文档

当前不作为稳定交接范围的内容：

- `20260409` 下的低延迟 `v3/realtime` 方案
- 本地调试目录：`.venv/`、`tmp/`
- 本地 bug 日志：`bug*.txt`
- 构建产物：`build/`
- 组件缓存：`managed_components/`

## 3. 当前稳定设备端能力

设备端当前已经稳定具备以下能力：

- 触摸屏触发
- 录音前提示音
- 等用户说话后采集 PCM
- Opus 编码
- framed-v1 WebSocket 流式上行
- 火山 ASR 优先，DashScope fallback 保留
- 回答音频下行播放
- 回答前开场提示音默认关闭
- OTA P3b inactive OTA partition 写入和 report 上报
- OTA P3c 002 canary boot switch、reboot、post-reboot confirm
- 板载喇叭播放
- 阶段化串口日志

P3c formalization is semi-automatic: release creation must use strict P3c validation, successful canaries are protected by manifest suppress, and canary closeout disables the release instead of deleting whitelist rows.

## 5. 推荐交付内容

如果要发给硬件同事进行编译、烧录、串口联调，默认只交付 compile-only 小包：

- `esp_compile_only_YYYY-MM-DD_vNN.tar.gz`

compile-only 小包必须包含：

- `esp_idf_demo/CMakeLists.txt`
- `esp_idf_demo/main/`
- `esp_idf_demo/partitions.csv`
- `esp_idf_demo/sdkconfig`
- `esp_idf_demo/sdkconfig.defaults`
- `esp_idf_demo/spiffs/`
- `esp_idf_demo/dependencies.lock`

compile-only 小包必须排除：

- `esp_idf_demo/build/`
- `esp_idf_demo/managed_components/`
- `.env`、`.env.*`
- `.git/`
- `tmp/`
- `data/`
- `indices/`
- 服务端源码、测试、历史交付包

生成命令示例：

```bash
tar --exclude='esp_idf_demo/build' \
  --exclude='esp_idf_demo/managed_components' \
  -czf tmp/esp_compile_only_YYYY-MM-DD_vNN.tar.gz \
  esp_idf_demo
```

`esp_flash_only_YYYY-MM-DD_vNN.tar.gz` 不是默认交付物，只能用于“无需编译、快速烧录采日志”的临时场景。

`esp_hardware_handoff_YYYY-MM-DD_vNN.tar.gz` 大包不是日常硬件传输包，只保留为完整归档/源码交接用途。

## 6. 交付前检查

交付前至少确认：

- `esp_idf_demo/main/config.h` 中的默认值符合当前文档
- `idf.py build` 已通过
- handoff 文档和设备端现状一致
- compile-only 压缩包不包含 `build/`、`managed_components/`、`.venv/`、`tmp/`、`.env`、`.git`、`data/`、`indices/`
- 对外发送前记录 `bytes`、`sha256`、包内文件数
